# MarketBoard public dashboard

Read-only market dashboard served by GitHub Pages through the existing private-source Actions workflow.

This release exposes Overview and Market Analysis. Local daily reports, investment research content, unreviewed local-only datasets, raw databases and model input details are excluded. Counts follow the reviewed asset configuration rather than a fixed historical watchlist size.

Visitors reload published data; the browser cannot run local collectors or edit the owner's settings. Each observation retains its actual data date and quality status.
